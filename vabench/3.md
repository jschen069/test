**2. 整理小猫测试数据**

官方通过 mapping 匹配视频，文件名需要是 **`kitten curled up meowing.mp4`，带空格**。下面脚本会复制视频、提取对应的单题元数据，并准备 mapping，不改动原视频和官方源码。

在容器执行：

```bash
python - <<'PY'
import csv
import json
import shutil
from pathlib import Path

repo = Path("/workspace/code/VABench-main")
run = Path("/workspace/vabench_kitten_test")
video = Path("/workspace/video/kittencurledupmeowing.mp4")
scene = "easy_bioacoustics"
idx = "kitten curled up meowing"

assert video.is_file(), f"视频不存在：{video}"

mapping = repo / "mapping/final_idx_to_prompt.csv"
with mapping.open(encoding="utf-8-sig", newline="") as f:
    rows = [
        row for row in csv.DictReader(f, delimiter="\t")
        if row["idx"] == idx
    ]
assert len(rows) == 1, f"mapping匹配数量异常：{len(rows)}"
prompt = json.loads('"' + rows[0]["prompt"] + '"')

items = json.loads(
    (repo / f"json_files/json_text/{scene}.json").read_text(encoding="utf-8")
)
selected = [item for item in items if item["prompt_en"] == prompt]
assert len(selected) == 1, f"官方题目匹配数量异常：{len(selected)}"

for folder in [
    run / "mapping_text",
    run / f"data/video/{scene}",
    run / f"data/audio/{scene}",
    run / "data/json",
]:
    folder.mkdir(parents=True, exist_ok=True)

shutil.copy2(mapping, run / "mapping_text/final_idx_to_prompt.csv")
shutil.copy2(video, run / f"data/video/{scene}/{idx}.mp4")
(run / f"data/json/{scene}.json").write_text(
    json.dumps(selected, ensure_ascii=False, indent=2),
    encoding="utf-8",
)

print("准备完成，题目数量：", len(selected))
print("官方Prompt：", prompt)
print("测试目录：", run)
PY
```

只保留这一题的 JSON，是为了避免把该场景其他尚未生成的视频也带入评测。

**4. 执行官方全部 15 项指标**

官方默认配置为两个 GPU 设置了：

```yaml
max_memory: {0: "80GB", 1: "80GB"}
device_map: "auto"
```

如果你的 GPU 环境符合这个配置，直接执行：

```bash
cd /workspace/vabench_kitten_test

export VABENCH_CACHE_DIR=/workspace/vabench-cache

set -o pipefail
python /workspace/code/VABench-main/evaluate.py \
  --data_dir /workspace/vabench_kitten_test/data \
  --config /workspace/code/VABench-main/vabench/config.yaml \
  --output_dir /workspace/vabench_kitten_test/results_all15 \
  2>&1 | tee /workspace/vabench_kitten_test/official_all15.log
```

**必须先 `cd /workspace/vabench_kitten_test`**，因为官方代码按当前工作目录查找 `mapping_text`。

如果 GPU 数量或显存不同，需要复制 `config.yaml` 并调整 `params.max_memory`，再将 `--config` 指向副本；15 个 `dimensions` 保留不变。

**这台机器的硬件可以运行官方全部 15 项指标，但截图中 8 张卡都正在忙，建议先获得两张空闲卡再执行。**

目前每张卡总显存约 **140 GiB**，已占用约 **130 GiB**，只剩 **10～11 GiB**，GPU 利用率也达到 **99%～100%**。`No running processes found` 不能说明卡空闲；在容器中可能看不到占用 GPU 的宿主机进程。

**1. 先确认可用资源**

在容器中执行：

```bash
nvidia-smi \
  --query-gpu=index,name,memory.total,memory.used,memory.free,utilization.gpu \
  --format=csv
```

由任务负责人或管理员确认当前作业，并分配两张空闲卡。不要直接终止未知进程。

**2. 分配到空闲卡后，选择这两张卡**

例如分配的是物理 **0、1** 号卡：

```bash
export CUDA_VISIBLE_DEVICES=0,1
export VABENCH_CACHE_DIR=/workspace/vabench-cache
```

如果分配的是 **6、7** 号卡，就改为：

```bash
export CUDA_VISIBLE_DEVICES=6,7
```

此时程序内部会将所选两张卡重新编号为 `cuda:0`、`cuda:1`，所以官方配置中的 `{0: "80GB", 1: "80GB"}` 可以保持不变。[NVIDIA 设备选择说明](https://docs.nvidia.com/cuda/cuda-programming-guide/05-appendices/environment-variables.html)

**3. 检查当前 Python 环境**

先进入已安装评测依赖的环境，再执行：

```bash
python - <<'PY'
import torch

print("PyTorch:", torch.__version__)
print("PyTorch编译CUDA版本:", torch.version.cuda)
print("CUDA可用:", torch.cuda.is_available())
print("可见GPU数量:", torch.cuda.device_count())

assert torch.cuda.is_available(), "PyTorch无法使用CUDA"
assert torch.cuda.device_count() == 2, "请检查GPU选择或容器设备映射"

for i in range(torch.cuda.device_count()):
    free, total = torch.cuda.mem_get_info(i)
    print(
        i, torch.cuda.get_device_name(i),
        f"空闲 {free / 1024**3:.1f} GiB",
        f"总计 {total / 1024**3:.1f} GiB",
    )
PY
```

截图中的 `CUDA Version: 13.2` 是驱动支持的 CUDA 版本信息，**不代表必须安装 CUDA 13.2 版 PyTorch**。先检查现有环境即可。[NVIDIA-SMI 说明](https://docs.nvidia.com/deploy/nvidia-smi/index.html)

**4. 执行全部指标**

如果已经执行了上一条回复中的小猫数据整理和 WAV 提取步骤，直接运行：

```bash
cd /workspace/vabench_kitten_test

set -o pipefail
python /workspace/code/VABench-main/evaluate.py \
  --data_dir /workspace/vabench_kitten_test/data \
  --config /workspace/code/VABench-main/vabench/config.yaml \
  --output_dir /workspace/vabench_kitten_test/results_all15 \
  2>&1 | tee /workspace/vabench_kitten_test/official_all15.log
```

**使用普通 `python` 启动即可，不需要 `torchrun` 或启动 8 个进程。**官方默认配置已包含全部 15 项，Qwen 模型使用 `device_map: auto` 分配设备。

注意，`max_memory: 80GB` 不会释放或预留显存，不能解决当前 GPU 已被其他任务占满的问题。小猫视频的唇形同步项也可能因没有人脸而没有有效结果。

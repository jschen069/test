  2. 安装主依赖（GPU 版）

  官方 requirement.txt 里有两个 OpenCV 包同时提供 cv2，会冲突。先生成安装副本：

  cd /workspace/code/VABench-main

  python - <<'PY'
  from pathlib import Path

  source = Path("requirement.txt")
  target = Path("requirement.gpu-fixed.txt")

  lines = []
  for line in source.read_text().splitlines():
      text = line.strip()
      if text.startswith("opencv-python=="):
          continue
      if text.startswith("opencv-python-headless=="):
          line = "opencv-python-headless==4.9.0.80"
      lines.append(line)

  target.write_text("\n".join(lines) + "\n")
  print("已生成:", target)
  PY

  安装：

  python -m pip install -r requirement.gpu-fixed.txt \
    -i https://repo.huaweicloud.com/repository/pypi/simple \
    --timeout 120 --retries 10 --resume-retries 20

  说明：

  - torch==2.6.0 / torchvision==0.21.0 / torchaudio==2.6.0 会从 PyPI 安装 Linux CUDA 12.4 wheel，不需要单独安装 CUDA Toolkit。
  - 这一步会下载数 GB 的 torch 和 NVIDIA 依赖，网络慢时不要用 conda run 捕获输出，直接 python -m pip 更容易看到进度。
  - decord==0.6.0 的 wheel 平台标签有问题，pip check 会报警，但实际解码可用。

  3. 安装 NISQA（关键：不能让它降级 torch）

  NISQA 2.0.post2 的元数据把 torch、torchvision、scipy、scikit-learn、matplotlib 全部锁死为旧版本。直接安装会把主环境降级，所以采用：

  1. 下载官方 wheel；
  2. 只修改 METADATA，把 5 个严格版本约束改成 >=；
  3. 用 --no-deps 安装。

  mkdir -p /tmp/nisqa-wheel && cd /tmp/nisqa-wheel

  python -m pip download nisqa==2.0.post2 --no-deps -d . \
    -i https://repo.huaweicloud.com/repository/pypi/simple                                                                                                                                                                                                                                                                                        

  python -m wheel unpack nisqa-2.0.post2-py3-none-any.whl -d unpacked

  python - <<'PY'
  from pathlib import Path
  
  meta = Path("unpacked/nisqa-2.0.post2/nisqa-2.0.post2.dist-info/METADATA")
  s = meta.read_text()

  for pkg in ["torch", "torchvision", "scipy", "scikit-learn", "matplotlib"]:
      old = f"Requires-Dist: {pkg} =="
      new = f"Requires-Dist: {pkg}>="
      assert old in s, f"未找到: {old}"
      s = s.replace(old, new)

  meta.write_text(s)
  print("METADATA 已放宽")
  PY

  mkdir -p fixed
  python -m wheel pack unpacked/nisqa-2.0.post2 -d fixed

  python -m pip install --no-deps fixed/nisqa-2.0.post2-py3-none-any.whl

  如果你不关心 pip check 是否干净，也可以跳过改元数据，直接：

  python -m pip install --no-deps nisqa==2.0.post2 \
    -i https://repo.huaweicloud.com/repository/pypi/simple

  运行时不受影响；只是 pip check 会报 5 条 NISQA 的版本冲突。

  NISQA 需要的 gdown==5.2.0、huggingface-hub==0.35.3 已在主依赖中，不需要额外装。

  4. 安装 ImageBind，并升级 pytorchvideo（关键）

  PyPI 的 pytorchvideo==0.1.5 有两个问题：

  - 它的 EncodedVideo.from_path() 不接受 ImageBind 传入的 sample_rate；
  - 它的 augmentations.py 还在 import 已被 torchvision 0.21 删除的 functional_tensor。

  GitHub 主分支已经修复这两点。只替换这一个依赖：

  # ImageBind（pin 到本机验证过的 commit）
  python -m pip install --no-deps \
    "git+https://github.com/facebookresearch/ImageBind.git@53680b02d7e37b19b124fa37bae4b6c98c38f5be"

  # pytorchvideo GitHub 主分支（pin 到验证过的 commit）
  python -m pip install --no-deps --no-build-isolation --force-reinstall \                                                                                                                                                                                                                                                                        
    "git+https://github.com/facebookresearch/pytorchvideo.git@2ac6ed361309cb25144636ad82dd8bd6a4970e0c"

  注意：

  - --no-deps 保证不会重新安装/降级 torch 等主依赖。
  - --force-reinstall 是必要的，因为 GitHub 版本的版本号仍然是 0.1.5，pip 会认为已经安装。
  - 这一步只改依赖，不改 VABench 源码。

  6. 模型缓存与 insightface 目录

  评测依赖的权重都在：

  export VABENCH_CACHE_DIR=/workspace/vabench-cache

  如果缓存是从别处拷贝的，LSA 使用的 insightface 期望目录是：

  /workspace/vabench-cache/checkpoints/auxiliary/models/buffalo_l

  而实际模型经常在：

  /workspace/vabench-cache/checkpoints/auxiliary/buffalo_l

  补一个软链即可，避免它联网下载时被 TLS 网关拦截：

  AUX=/workspace/vabench-cache/checkpoints/auxiliary
  if [ -d "$AUX/buffalo_l" ] && [ ! -e "$AUX/models/buffalo_l" ]; then
    mkdir -p "$AUX/models"
    ln -s ../buffalo_l "$AUX/models/buffalo_l"
  fi

  如果缓存不完整，VABench 首次评测会尝试自动下载权重。本机处于 TLS 检查网关后，建议提前把缓存准备好，而不是依赖运行时下载。

  7. 准备测试数据

  假设视频是 /workspace/video/kittencurledupmeowing.mp4，场景为 easy_bioacoustics，题目 idx 为 kitten curled up meowing：

  python - <<'PY'
  import csv, json, shutil, subprocess
  from pathlib import Path

  repo = Path("/workspace/code/VABench-main")
  run = Path("/workspace/vabench_kitten_test")
  video = Path("/workspace/video/kittencurledupmeowing.mp4")

  scene = "easy_bioacoustics"
  idx = "kitten curled up meowing"

  assert video.is_file(), f"视频不存在: {video}"

  mapping = repo / "mapping/final_idx_to_prompt.csv"
  with mapping.open(encoding="utf-8-sig", newline="") as f:
      rows = [r for r in csv.DictReader(f, delimiter="\t") if r["idx"] == idx]                                                                                                                                                                                                                                                                    
  assert len(rows) == 1, f"mapping 匹配数量: {len(rows)}"

  prompt = json.loads('"' + rows[0]["prompt"] + '"')
  items = json.loads((repo / f"json_files/json_text/{scene}.json").read_text(encoding="utf-8"))
  selected = [it for it in items if it["prompt_en"] == prompt]
  assert len(selected) == 1, f"题目匹配数量: {len(selected)}"

  video_dir = run / "data/video" / scene
  audio_dir = run / "data/audio" / scene
  json_dir = run / "data/json"
  mapping_dir = run / "mapping_text"

  for d in (video_dir, audio_dir, json_dir, mapping_dir):                                                                                                                                                                                                                                                                                         
      d.mkdir(parents=True, exist_ok=True)

  target_video = video_dir / f"{idx}.mp4"
  target_audio = audio_dir / f"{idx}.wav"
  
  shutil.copy2(video, target_video)
  shutil.copy2(mapping, mapping_dir / mapping.name)
  (json_dir / f"{scene}.json").write_text(
      json.dumps(selected, ensure_ascii=False, indent=2),
      encoding="utf-8",
  )

  subprocess.run(
      [
          "ffmpeg", "-nostdin", "-y",
          "-i", str(target_video),
          "-map", "0:a:0", "-vn",
          "-c:a", "pcm_s16le",
          str(target_audio),
      ],
      check=True,
  )

  print("准备完成:", run)
  print("视频:", target_video)
  print("音频:", target_audio)
  PY

  注意：

  - 视频必须带音轨；如果视频没有音频，需要单独提供 WAV。
  - 文件名前缀必须与 mapping 中的 idx 一致。
  - 场景 JSON 必须包含对应题目，且 prompt_en 与 mapping 中的 prompt 一致。

  9. 两个已知限制

  这两项不是依赖问题，也不是环境配置问题：

  1. second_lsa：需要视频中检测到人脸。小猫视频没有人脸，LSA 会返回空结果，CSV 中为 -1。
  2. second_desync：官方 Synchformer 按 5 秒片段训练。如果视频只有 4 秒左右，token 数不匹配，代码会捕获异常并回退为 1.0。按你的要求没有修改这部分源码；如果输入是标准 5 秒片段，就不会触发。

  除此之外，其余指标在统一环境 vabench311 中都可以正常执行。

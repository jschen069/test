**正常情况下会安装。**我核对了 VABench 的 [requirement.txt](C:/需求/vabench/VABench/requirement.txt:84)，里面明确包含：

```text
onnxruntime-gpu==1.23.0
```

这个包安装后，在代码中使用的名字就是 `import onnxruntime`。[ONNX Runtime 官方安装说明](https://onnxruntime.ai/docs/install/)

但你当前的报错只能证明：**执行评测的这个 `python3` 环境找不到它。**可能是：

- `pip install -r requirement.txt` 中途失败，没有完成安装。
- 当时的 `pip` 和现在的 `python3` 属于不同环境。
- 切换到新建的 Python 3.11 环境后，没有重新安装全部依赖。

**先检查当前环境：**

```bash
python3 -c "import sys; print('当前Python:', sys.executable)"
python3 -m pip --version
python3 -m pip show onnxruntime-gpu onnxruntime
```

如果提示找不到包，在**同一个终端、同一个评测环境**中补装：

```bash
python3 -m pip install "onnxruntime-gpu==1.23.0"
```

这里使用 `python3 -m pip`，确保安装到后续运行评测的那个 Python 中。

**然后验证：**

```bash
python3 - <<'PY'
import onnxruntime as ort
import runpy

print("ONNX Runtime版本:", ort.__version__)
print("可用providers:", ort.get_available_providers())

module = runpy.run_path(
    "/workspace/code/VABench-main/third_party/DNS-Challenge/DNSMOS/dnsmos_local.py"
)
assert "ComputeScore" in module
print("DNSMOS评分代码导入成功")
PY
```

再检查其他包的依赖关系：

```bash
python3 -m pip check
```

**这次不是 `dnsmos_local.py` 文件不存在，而是它导入依赖失败。**官方代码捕获这个异常后统一报成了 `DNSMOS library not found`，所以最终错误提示容易误导。先通过上面的导入验证，再重新启动评测，不需要重新下载视频或权重。




**不能据此认定是 Python 3.12 导致的。**这次明确的错误是：

```text
No module named 'onnxruntime'
```

意思是：**当前运行评测的 Python 环境找不到这个包**。如果版本不兼容导致它此前安装失败，才可能间接与 Python 版本有关，需要看安装日志确认。

```bash

python3 -c "import sys; print(sys.executable)"
python3 -m pip show onnxruntime-gpu
```

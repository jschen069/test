这份日志有 **3 个独立问题**，其中真正导致程序退出的是 **ImageBind 的依赖兼容问题**。

| 项目 | 当前情况 |
|---|---|
| ImageBind | PyTorchVideo 引用了新版 torchvision 已移除的接口，导致退出 |
| Synchformer | 输入长度 156，与模型固定位置编码长度 198 不匹配 |
| 唇形同步 LSA | 没检测到人脸，小猫素材无法完成这项评测 |

**1. 先修复 ImageBind，不要降级 torch/torchvision**

当前错误：

```text
No module named 'torchvision.transforms.functional_tensor'
```

这个接口从 torchvision 0.17 起已移除。你安装的 PyTorchVideo 仍引用它。[Torchvision 官方说明](https://github.com/pytorch/vision/releases/tag/v0.17.0)

ImageBind 官方指定了一个已改用公共接口的 PyTorchVideo 提交，直接安装该版本。[ImageBind 官方依赖](https://github.com/facebookresearch/ImageBind/blob/main/requirements.txt)

在主环境执行：

```bash
conda activate vabench311

python3 -m pip install --force-reinstall --no-deps \
  "git+https://github.com/facebookresearch/pytorchvideo.git@6cdc929315aab1b5674b6dcf73b16ec99147735f" \
  -i https://repo.huaweicloud.com/repository/pypi/simple
```

这里的 `--no-deps` **仅用于替换这个已明确有问题的依赖，保留现有 torch 等包**；不是用它绕过其他版本冲突。

安装后验证：

```bash
python3 - <<'PY'
import torch
import torchvision
from pytorchvideo import transforms
from imagebind import data

print("torch:", torch.__version__)
print("torchvision:", torchvision.__version__)
print("PyTorchVideo和ImageBind导入成功")
PY

python3 -m pip check
```

这能验证当前导入错误已解决，完整 ImageBind 推理仍需随后运行。

**2. Synchformer 报错与短视频有关**

```text
The size of tensor a (156) must match ... tensor b (198)
```

模型配置的位置编码固定为 **198**，但本次输入只有 **156**。官方代码在不足 14 段时直接传入短序列，未匹配模型要求。结合此前约 4 秒的小猫视频，**短视频导致分段不足是最可能原因**。

先确认实际时长：

```bash
ffprobe -v error \
  -show_entries format=duration \
  -of default=noprint_wrappers=1 \
  "/workspace/vabench_kitten_test/data/video/easy_bioacoustics/kitten curled up meowing.mp4"
```

建议重新生成同题的 **10 秒真实音视频**，替换测试副本并重新提取 WAV。不要直接修改位置编码长度，也不要把循环延长的素材当作正式生成结果。

**尤其注意：官方代码会把本次异常写成兜底分数 `1.0`，这个值不是有效同步成绩。**对应逻辑见 [second_desync.py](C:/需求/vabench/VABench/vabench/second_desync.py)。

**3. LSA 无人脸不是依赖安装问题**

日志显示 S3FD、InsightFace、SyncNet 已加载，随后出现：

```text
No face detected
```

小猫无法验证人物唇形同步。该项需要另外加入**官方人物说话题对应的视频、文件名和 JSON**，本次应记录为无有效结果。

先完成第 1 步的导入验证，再重新执行 `other14.yaml`。当前素材仍不能产生全部 14 项有效成绩；Synchformer 和 LSA 需要按上面两点补齐素材。其余弃用类 `Warning` 不是这次退出的原因。

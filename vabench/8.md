**这次主清单安装已经完成，但安装后发现 NISQA 的依赖被破坏。**日志末尾的 `Successfully installed` 和前面的依赖冲突提示可以同时出现。

冲突如下：

| 包 | NISQA 2.0.post2 要求 | 当前主环境 |
|---|---|---|
| torch | 2.2.1 | 2.6.0 |
| torchvision | 0.17.1 | 0.21.0 |
| scipy | 1.12.0 | 1.16.2 |
| scikit-learn | 1.4.1.post1 | 1.7.2 |
| matplotlib | 3.8.3 | 3.10.6 |

我已核对 NISQA 安装包元数据，这些都是严格的 `==` 要求。**此前只修正 OpenCV 还不够；我之前建议给 NISQA 加主清单约束安装，也无法解决这个冲突，需要纠正。**

`--dry-run -r ...` 主要检查本次安装目标能否解析，不保证此前单独安装的所有包仍兼容。pip 官方也说明，分次安装可能破坏已有包的依赖。[pip 官方说明](https://pip.pypa.io/en/stable/user_guide/#changes-to-the-pip-dependency-resolver-in-20-3-2020)

**建议采用两个环境，仍然执行官方源码：NISQA 单独运行，当前环境运行其他 14 项。**不要把主环境降回 torch 2.2.1。

**1. 创建 NISQA 环境**

```bash
conda create -n vabench-nisqa python=3.11 pip -y

conda run -n vabench-nisqa python3 -m pip install \
  "nisqa==2.0.post2" \
  "gdown==5.2.0" \
  "huggingface-hub==0.35.3" \
  -i https://repo.huaweicloud.com/repository/pypi/simple

conda run -n vabench-nisqa python3 -m pip check
```

这里不要添加 `-c requirement.gpu-fixed.txt`，也不要往这个环境安装主清单。

**2. 从官方配置生成两份配置**

在当前主环境执行：

```bash
python3 - <<'PY'
from pathlib import Path
import yaml

repo = Path("/workspace/code/VABench-main")
run = Path("/workspace/vabench_kitten_test")
cfg = yaml.safe_load((repo / "vabench/config.yaml").read_text())

nisqa_cfg = {"dimensions": ["first_nisqa"], "params": {}}
other_cfg = dict(cfg)
other_cfg["dimensions"] = [
    dim for dim in cfg["dimensions"] if dim != "first_nisqa"
]

for name, content in [
    ("nisqa_only.yaml", nisqa_cfg),
    ("other14.yaml", other_cfg),
]:
    path = run / name
    path.write_text(yaml.safe_dump(content, sort_keys=False))
    print(path)
PY
```

**3. 先验证独立环境中的 NISQA**

```bash
cd /workspace/vabench_kitten_test
export CUDA_VISIBLE_DEVICES=6,7
export VABENCH_CACHE_DIR=/workspace/vabench-cache
set -o pipefail

conda run --no-capture-output -n vabench-nisqa \
  python3 -u /workspace/code/VABench-main/evaluate.py \
  --data_dir /workspace/vabench_kitten_test/data \
  --config /workspace/vabench_kitten_test/nisqa_only.yaml \
  --output_dir /workspace/vabench_kitten_test/results_nisqa \
  2>&1 | tee /workspace/vabench_kitten_test/nisqa.log
```

这一步通过后，再处理主环境。

**4. 主环境移除冲突的 NISQA，检查其余依赖**

```bash
conda activate vabench311

python3 -m pip uninstall -y nisqa
python3 -m pip check
```

CLIP、ImageBind 若尚未安装，仍需要完成它们的安装及导入检查。

```bash
cd /workspace/vabench_kitten_test

python3 -u /workspace/code/VABench-main/evaluate.py \
  --data_dir /workspace/vabench_kitten_test/data \
```

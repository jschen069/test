这些错误有不同原因，**不能视为依赖已经安装完成**：

| 日志 | 原因 |
|---|---|
| `Collecting https://repo.huaweicloud.com/.../simple` | 镜像地址前漏了 `-i`，被当成待安装文件 |
| `HTTP error 429` | 服务端返回限流；当前请求还包含上述地址用法错误 |
| `Operation cancelled by user` | 安装被 Ctrl+C 中断，尚未完成 |
| `Cannot find command 'git'` | 容器没有安装 Git，无法安装 `git+https://...` 包 |
| 上一份日志中的 NumPy 冲突 | 官方依赖版本互相矛盾，Python 3.11 下也存在 |

`Using cached` 只代表找到了缓存文件，**不代表已安装成功**。pip 还要完成依赖解析、构建和安装。[pip 官方安装流程](https://pip.pypa.io/en/stable/cli/pip_install/)

建议按下面顺序处理，每一步成功后再继续。

**1. 安装 Git，确认当前 Python 环境**

```bash
apt-get update
apt-get install -y git

git --version
python3 --version
python3 -c "import sys; print(sys.executable)"
python3 -m pip --version
```

如果使用 `vabench311`，Python 应显示 3.11，路径应位于该 Conda 环境中。

**2. 修正官方依赖清单中的已知冲突**

保留原文件，生成一个安装副本：

```bash
cd /workspace/code/VABench-main

python3 - <<'PY'
from pathlib import Path

source = Path("requirement.txt")
target = Path("requirement.gpu-fixed.txt")

lines = []
for line in source.read_text().splitlines():
    text = line.strip()
    if text.startswith("opencv-python=="):
        continue
    if text.startswith("opencv-python-headless=="):
        line = "opencv-python-headless==4.9.0.80"
    lines.append(line)

target.write_text("\n".join(lines) + "\n")
print("已生成：", target)
PY
```

这个副本只调整 OpenCV：

- 保留 `numpy==1.26.4`。
- 将 headless OpenCV 改为与其兼容的 `4.9.0.80`。
- 移除另一套提供相同 `cv2` 模块的 `opencv-python`。

OpenCV 官方建议同一环境只安装一种发行包，容器无 GUI 场景适合使用 headless 版本。[OpenCV 包说明](https://pypi.org/project/opencv-python-headless/4.9.0.80/)

**3. 先检查依赖能否解析**

```bash
python3 -m pip install --dry-run \
  -r requirement.gpu-fixed.txt \
  -i https://repo.huaweicloud.com/repository/pypi/simple
```

这一步**不向当前环境正式安装目标包**，但可能下载包和准备构建元数据。如果仍报冲突，先处理新错误；这份副本目前只修正了已确认的 NumPy/OpenCV 问题。

如果正确使用 `-i` 后仍持续返回 429，可以改用官方源：

```bash
python3 -m pip install --dry-run \
  -r requirement.gpu-fixed.txt \
  -i https://pypi.org/simple
```

**4. 解析成功后，逐条安装**

以下每条命令单独执行，确认成功再执行下一条：

```bash
python3 -m pip install \
  -r requirement.gpu-fixed.txt \
  -i https://repo.huaweicloud.com/repository/pypi/simple
```

```bash
python3 -m pip install "nisqa==2.0.post2" \
  -c requirement.gpu-fixed.txt \
  -i https://repo.huaweicloud.com/repository/pypi/simple
```

```bash
python3 -m pip install "git+https://github.com/openai/CLIP.git" \
  -c requirement.gpu-fixed.txt \
  -i https://repo.huaweicloud.com/repository/pypi/simple
```

```bash
python3 -m pip install "git+https://github.com/facebookresearch/ImageBind.git" \
  -c requirement.gpu-fixed.txt \
  -i https://repo.huaweicloud.com/repository/pypi/simple
```

`-c` 用来约束后续安装，避免无意改变已确定的版本。GitHub 源码仍从 GitHub 下载，PyPI 镜像不会代理 Git 克隆。

最后执行：

```bash
python3 -m pip check
```

再运行之前提供的全量依赖检查脚本，确认关键模块能够导入后，才重新启动评测。

下面统一使用 **`python3` 命令**。按你容器中的实际路径，依次执行即可。

**1. 选择空闲 GPU，设置权重路径**

你之前的截图中所有 GPU 都在忙，先确认已分配两张空闲卡。下面以 **0、1 号卡**为例：

```bash
export CUDA_VISIBLE_DEVICES=0,1
export VABENCH_CACHE_DIR=/workspace/vabench-cache

python3 --version
python3 -c "import torch; print('PyTorch:', torch.__version__); print('CUDA:', torch.cuda.is_available()); print('GPU数量:', torch.cuda.device_count())"
```

应使用安装了 VABench 依赖的 Python 3.11 环境，`CUDA` 应为 `True`。

**2. 准备单条小猫测试数据**

这段使用 Python 3 语法，会复制视频、准备官方单题 JSON 和 mapping，并调用 FFmpeg 提取 WAV：

```bash
python3 - <<'PY'
import csv
import json
import shutil
import subprocess
from pathlib import Path

repo = Path("/workspace/code/VABench-main")
cache = Path("/workspace/vabench-cache")
run = Path("/workspace/vabench_kitten_test")
video = Path("/workspace/video/kittencurledupmeowing.mp4")

scene = "easy_bioacoustics"
idx = "kitten curled up meowing"

assert video.is_file(), f"视频不存在：{video}"
assert (cache / "Qwen2.5_omni_7B/config.json").is_file(), "Qwen缓存路径不正确"

mapping = repo / "mapping/final_idx_to_prompt.csv"
with mapping.open(encoding="utf-8-sig", newline="") as f:
    rows = [
        row for row in csv.DictReader(f, delimiter="\t")
        if row["idx"] == idx
    ]
assert len(rows) == 1, f"mapping匹配数量异常：{len(rows)}"

prompt = json.loads('"' + rows[0]["prompt"] + '"')
source_json = repo / f"json_files/json_text/{scene}.json"
items = json.loads(source_json.read_text(encoding="utf-8"))
selected = [item for item in items if item["prompt_en"] == prompt]
assert len(selected) == 1, f"题目匹配数量异常：{len(selected)}"

video_dir = run / "data/video" / scene
audio_dir = run / "data/audio" / scene
json_dir = run / "data/json"
mapping_dir = run / "mapping_text"

for folder in (video_dir, audio_dir, json_dir, mapping_dir):
    folder.mkdir(parents=True, exist_ok=True)

target_video = video_dir / f"{idx}.mp4"
target_audio = audio_dir / f"{idx}.wav"

shutil.copy2(video, target_video)
shutil.copy2(mapping, mapping_dir / mapping.name)

(json_dir / f"{scene}.json").write_text(
    json.dumps(selected, ensure_ascii=False, indent=2),
    encoding="utf-8",
)

subprocess.run(
    [
        "ffmpeg", "-nostdin", "-y",
        "-i", str(target_video),
        "-map", "0:a:0", "-vn",
        "-c:a", "pcm_s16le",
        str(target_audio),
    ],
    check=True,
)

print("准备完成")
print("题目数量：", len(selected))
print("视频：", target_video)
print("音频：", target_audio)
print("测试目录：", run)
PY
```

该步骤不修改原视频或官方源码。

**3. 启动官方全部 15 项评测**

官方默认配置按两张 GPU、每张 `80GB` 的模型加载预算设置。获得空闲 H200 后，可以先保留这份配置。

```bash
cd /workspace/vabench_kitten_test

set -o pipefail

python3 -u /workspace/code/VABench-main/evaluate.py \
  --data_dir /workspace/vabench_kitten_test/data \
  --config /workspace/code/VABench-main/vabench/config.yaml \
  --output_dir /workspace/vabench_kitten_test/results_all15 \
  2>&1 | tee /workspace/vabench_kitten_test/official_all15.log
```

其中：

- `python3 -u`：实时输出日志。
- 官方 `config.yaml`：包含全部 15 项指标。
- Qwen2.5-Omni-7B：评测到对应指标时自动加载，无需另起服务。
- **必须在 `/workspace/vabench_kitten_test` 下启动**，确保官方代码找到 `mapping_text`。
